## 🎮 О проекте

Этот проект — полный реверс-инжиниринг оригинальной **Devil May Cry 1** для PlayStation 2 с перекомпиляцией под Windows x86_64. Игра работает как нативное Windows-приложение **без эмуляции PS2**.

### Ключевые особенности

- ✅ **Нативная x86_64 сборка** — никаких эмуляторов
- ✅ **Современное управление** в стиле DMC 4/5
- ✅ **Оригинальные ассеты** — модели, текстуры, музыка из PS2-версии
- ✅ **OpenGL рендеринг** вместо Graphical Synthesizer
- ✅ **OpenAL аудио** вместо SPU2
- ✅ **Система комбо и стилей**

### Цели проекта

| Цель | Описание |
|------|----------|
| 🎯 **Нативность** | Полностью перекомпилированный код для x86_64 |
| 🎯 **Управление** | WASD + мышь, как в DMC 4/5 |
| 🎯 **Оригинальность** | Сохранение всех оригинальных ассетов PS2 |
| 🎯 **Производительность** | Стабильные 60+ FPS на современных ПК |

## 🏗️ Архитектура

Проект заменяет PS2-системы на современные PC-аналоги:

| PS2 System | PC Replacement | Описание |
|------------|----------------|----------|
| **MIPS R5900** | x86_64 (GCC/MinGW) | Перекомпиляция кода процессора |
| **GS** (Graphical Synthesizer) | **OpenGL 4.6** | 3D рендеринг |
| **SPU2** (Sound Processor) | **OpenAL** | 3D аудио |
| **SIO** (Input) | **Win32 API** | Клавиатура + мышь |
| **CDROM** | **NTFS** | Файловая система |

## 🔨 Сборка

### Требования

- **MinGW-w64** (GCC 11+ для x86_64 Windows)
- **MSYS2** (рекомендуется для установки MinGW-w64)
- **OpenGL** (встроено в Windows 10/11)
- **OpenAL** (опционально, для звука)

### Установка зависимостей (MSYS2)

```bash
# Установка MinGW-w64 через MSYS2
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-make
```

### Команды сборки

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR-USERNAME/dmc1-pc-port.git
cd dmc1-pc-port

# Скомпилировать
make

# Запустить
make run

# Очистить build
make clean

# Установить PS2 данные (если есть)
make install-data
```

### Выходной файл

После успешной сборки:
```
dmc1-pc-port/DMC1.exe    # Нативный Windows-исполняемый файл
```

## 📂 PS2 Data Files

Проект использует оригинальные файлы из ISO PS2-версии игры:

| Папка | Содержимое |
|-------|------------|
| `DATA/PLD/` | 3D модели персонажей |
| `DATA/FSD/` | Уровни и сцены |
| `DATA/EMD/` | 3D модели врагов |
| `DATA/ETC/` | Текстуры (.t32) и звуки |
| `DATA/ADS/` | События и битвы |
| `DATA/MOVIE/` | Кат-сцены (.pss) |
| `DATA/MODULES/` | IRX модули |

> **Примечание:** Данные извлекаются из оригинального ISO PS2-версии игры.
